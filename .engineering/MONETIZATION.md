# NERVA Monetization

Status: CANONICAL_CANDIDATE — M00

## Business principle
NERVA earns because it provides monitoring, policy automation and infrastructure, not because users take more risk or lose more money.

## V0.1 / early product
- Free: basic risk monitoring, limited policies/dry-run, Flight Recorder history.
- Pro: more active policies/positions, advanced analytics, longer evidence history, richer alerts/automation.
- Execution fee: optional small transparent fee only where technically/economically appropriate; disclosed before authority is granted.
- Perpl builder-code economics: IMPORTANT, not NECESSARY; only if current Perpl rules support it and user authorization/disclosure is explicit.

## B2B path
Wallets, DEXs, fintechs and protocols can integrate NERVA Risk/Policy/Evidence capabilities via SDK/API. Commercial models may include usage tiers, platform subscription or enterprise support/SLA.

## Never
- hidden spread;
- dark-pattern subscription;
- payment for order flow without clear user disclosure/decision;
- selling user wallet/behavior data to advertisers;
- fee based on "loss avoided";
- incentive to increase leverage/churn;
- mandatory token purchase to access basic safety.

## Metrics
Track ethically useful metrics: protected positions, active policies, successful/refused actions by reason, false-positive/false-trigger investigations, API uptime/latency, retained users, paid conversion, B2B usage. Do not optimize a vanity metric that conflicts with user safety.
