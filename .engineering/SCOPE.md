# NERVA Scope

Status: CANONICAL_CANDIDATE — M00

## V0.1 NECESSARY
- Monad network support.
- Perpl position/market adapter and bounded protective execution path.
- Deterministic Risk Engine.
- Structured Policy DSL/schema and validator.
- Natural-language-to-policy proposal with explicit confirmation.
- Policy evaluation and trigger engine.
- Dry-run/simulation/preflight.
- Least-privilege wallet/signing adapter; MetaMask Agent Wallet is the target integration subject to capability preflight.
- Envio-backed/onchain indexing where it materially improves evidence/analytics, subject to capability preflight.
- Flight Recorder with decision/execution/refusal receipts.
- Web dashboard, policy creation, risk state and execution timeline.
- Testnet/controlled-demo path plus gated mainnet configuration.
- CI, observability, security checks, deployment and Metropolis submission assets.

## IMPORTANT if schedule and evidence permit
- Additional risk metric beyond core set.
- Browser notifications.
- Onchain policy/receipt commitment if it adds verifiability without adding unsafe complexity.
- Builder code / transparent Perpl fee integration after user consent.
- One additional sponsor integration only if it improves the product and does not threaten DoD.

## FUTURE
- Aave/Euler/lending protection.
- Kuru/spot protection and intents.
- Yield/LP rebalancing.
- Cross-protocol portfolio policies.
- Insurance integration.
- Mobile native app.
- Cross-chain support.
- Institutional policy engine and B2B console.
- Advanced option/volatility risk.
- Protocol-risk/depeg intelligence.

## OUT OF SCOPE V0.1
- Custody of user keys.
- Seed phrase collection.
- Unlimited autonomous authority.
- Profit promises or "guaranteed liquidation protection".
- Market-making strategy.
- Token/NERVA coin/tokenomics.
- DAO/governance token.
- Copy trading/social trading.
- Unbounded leverage.
- Hidden spread/fees.
- Production mainnet execution without release gate.
- Building our own oracle/bridge/wallet.

## Scope admission rule
Only NECESSARY work enters automatically. IMPORTANT requires evidence that schedule/DoD benefits outweigh risk. FUTURE requires a later version decision.
